Manual copy reference page

How to use it. 1) Select the content of #copy-source (or use the "Select all" button). 2) Copy with Cmd/Ctrl+C. 3) Paste with Cmd/Ctrl+V into a test page of the editor. 4) Compare against the list below.

Expected after pasting: H1-H3 headings, bold, italic, strike, colours, safe link, quote, numbered list, indented bullets, table with header and empty cells, code, rendered Mermaid diagram, and Text → image → Text in that order. All content is synthetic; it contains no real data.
